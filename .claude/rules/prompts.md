# Prompt Standards — GalSen IA

## Language
All prompt files and system prompts must be written in **English**.

## Principles
- Write clear, specific and unambiguous prompts.
- Prefer structured prompts (with sections) over long paragraphs.
- Always define the expected output format when possible.
- Include constraints and boundaries in the prompt.
- Avoid unnecessary verbosity.

## Good Practices
- Put the most important instructions at the top.
- Use bullet points or numbered lists for rules.
- When creating agents or skills, keep the prompt focused on one responsibility.
- Test and refine prompts over time.

## Storage
Prompt-related files should live in clear locations (skills, agents, or dedicated prompt folders) and be referenced from the knowledge index when important.
