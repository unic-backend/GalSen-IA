# ADR-000: Template for Architecture Decision Records

## Status
Accepted

## Date
2026-07-28

## Context
We need a standard way to record important technical decisions so that Claude Code and humans can understand why choices were made, even years later.

## Decision
All significant architecture and technology decisions must be written as Architecture Decision Records (ADRs) using this template.

## Consequences
- Decisions become permanent and searchable.
- Future contributors (and Claude Code) can understand the reasoning.
- We avoid repeating the same discussions.

## Notes
Copy this file and rename it (example: `001-choose-initial-stack.md`) when making a real decision.
